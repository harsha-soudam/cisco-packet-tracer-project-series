## 📖 Overview

This project demonstrates the design and implementation of a small office Local Area Network (LAN) using Cisco Packet Tracer.

The network consists of employee workstations, a manager workstation, a file server, a network printer, and a Cisco 2960 Layer 2 switch connected using a star topology.

This project focuses on understanding Ethernet communication, IP addressing, ARP, ICMP, and basic network troubleshooting.

---

## 🎯 Objectives

- Design a small office LAN
- Configure static IP addressing
- Understand Layer 2 switching
- Learn packet flow
- Analyze ARP and ICMP communication
- Practice network troubleshooting
